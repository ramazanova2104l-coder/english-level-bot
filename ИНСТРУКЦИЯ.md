# Бот «Тест уровня английского»: как запустить

## Что умеет бот
1. Спрашивает цель (ОГЭ/ЕГЭ, разговорный, работа, путешествия, для ребёнка).
2. Даёт 20 вопросов по грамматике (A1–C1), потом аудирование (рассказ на минуту + 4 вопроса) и чтение (короткий текст + 4 вопроса). Варианты ответов перемешиваются.
3. Показывает уровень с понятным описанием, напоминает, что первый урок бесплатный.
4. Присылает PDF «Как учить английский на вашем уровне» (свой для каждого уровня) и промокод на скидку на первый месяц.
5. Кнопки: «Записаться на бесплатный урок», «Speaking Club» (ведёт в Instagram со словом CLUB), «Пройти заново».
6. Заявку (имя + телефон/контакт + уровень + цель) сразу присылает вам в Telegram.
7. Также присылает короткое уведомление о каждом, кто прошёл тест, даже без заявки: этим людям можно написать первой.

Ваши команды в боте: `/myid` показывает ваш ID, `/leads` присылает таблицу всех заявок.

## Шаг 1. Создать бота (5 минут)
1. В Telegram откройте **@BotFather** и отправьте `/newbot`.
2. Придумайте имя (например, «Английский с Лейлой: тест уровня») и адрес, который заканчивается на `bot` (например, `ramazanova_eng_test_bot`).
3. BotFather пришлёт **токен**: длинную строку вида `123456:ABC...`. Это пароль от бота, никому его не показывайте.

## Шаг 2. Аудио (необязательно)
Аудио уже готово: `media/listening.mp3` (озвучка синтезом речи). Если захотите заменить его своим голосом, текст для записи лежит в `media/ТЕКСТ_ДЛЯ_ЗАПИСИ_АУДИО.txt`.

## Шаг 3. Запустить на хостинге
Бот должен работать на сервере круглосуточно. Подойдёт любой хостинг для Python-ботов, например Bothost (оплата в рублях, есть бесплатный или очень дешёвый тариф).
1. Загрузите туда файлы из папки `english-level-bot` (или архив).
2. В настройках укажите переменную `BOT_TOKEN` = ваш токен.
3. Команда запуска: `python bot.py`.
4. Откройте своего бота, отправьте `/myid`, скопируйте число и добавьте вторую переменную `ADMIN_ID` = это число. Перезапустите бота. Теперь заявки будут приходить вам.

## Как поменять тексты и вопросы
- Приветствие, цену, текст про Speaking Club, список целей: файл `config.py`.
- Промокод и размер скидки: `PROMO_CODE` и `PROMO_TEXT` в `config.py`.
- Советы в PDF для каждого уровня: файл `recommendations.py`.
- Вопросы, текст для чтения, вопросы к аудио и описания уровней: файл `questions.py`. В каждом вопросе **первый вариант ответа правильный**, бот сам перемешивает их при показе.

## Как считается уровень
У каждого вопроса есть уровень. На A1 это 4 вопроса грамматики, на A2, B1, B2 и C1 по 6 (4 грамматики, 1 аудио, 1 по тексту). Уровень засчитывается, если на нём и на всех уровнях ниже верно минимум 60%: 3 из 4 на A1 и 4 из 6 на остальных. Например: A1 4/4, A2 5/6, B1 3/6 → результат A2.
